# QA E-commerce Testing

## Sobre o projeto

Projeto de Quality Assurance (QA) voltado à validação de funcionalidades de uma aplicação de comércio eletrônico.

O objetivo é aplicar práticas de testes manuais, testes de API e automação, simulando atividades realizadas no dia a dia de um profissional de QA.

## Aplicação em teste

- Nome: SauceDemo
- URL: https://www.saucedemo.com/

## Tecnologias e ferramentas

- Jira – Gerenciamento de tarefas e acompanhamento da Sprint
- Git e GitHub – Versionamento
- Postman – Testes de API
- Playwright – Automação de testes
- TypeScript – Linguagem de programação

## Estrutura do projeto

- docs: documentação do projeto
- tests/manual: testes manuais
- tests/api: testes de API
- tests/e2e: testes automatizados
- evidence: evidências das execuções

## Metodologia

Scrum, com planejamento de Sprint, acompanhamento das atividades e retrospectiva.
